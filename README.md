# People's Hand Foundation

Full-stack NGO/social-service website starter with React/Vite frontend and Express/SQLite backend.

## Run

### Backend
```bash
cd backend
npm install
npm run dev
```
Runs on http://localhost:5000

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs on http://localhost:5173

Demo admin: `admin@peopleshand.org` / `Admin@123`

> Replace placeholder contact, founder, payment and social-media data before production. Payment gateway integration is intentionally represented by a safe placeholder flow until real merchant credentials are supplied.
